# Virtual Museum

3D Art Museum with Timeline — interactive exhibitions for digital art.

## Concept
- Three.js based 3D gallery
- Timeline-based exhibition navigation
- Interactive artwork displays
- Multilingual (DE + EN)
- Monetization: Buy Me a Coffee / donations

## Status
📝 Concept phase — development starts after ERES Vienna (July 2026)

## Tech Stack (planned)
- Three.js (3D rendering)
- React or Vanilla JS (frontend)
- Node.js (backend)
- Docker deployment
